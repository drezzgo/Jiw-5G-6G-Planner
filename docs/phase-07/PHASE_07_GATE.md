# Gate de Fase 7

## Automatizado

- [ ] todos los tests anteriores pasan.
- [ ] tests de Fresnel pasan.
- [ ] tests de análisis de terreno pasan.
- [ ] `pnpm build` pasa.

## Página principal

- [ ] `/` ya no está vacía.
- [ ] enlaza a `/calculadora`.
- [ ] enlaza a `/planner`.
- [ ] diferencia claramente ambos módulos.
- [ ] muestra capacidades implementadas.
- [ ] no afirma que la herramienta sea un planificador profesional certificado.

## Terreno

- [ ] se obtiene perfil desde Open-Meteo.
- [ ] se atribuye Copernicus DEM GLO-90.
- [ ] se limita a 100 muestras.
- [ ] gráfico de elevación funciona.
- [ ] se muestra línea directa.
- [ ] se muestra límite inferior de 60% F1.
- [ ] se detecta obstrucción de terreno.
- [ ] se detecta invasión de F1.
- [ ] mover gNB/UE marca el perfil como desactualizado.
- [ ] usuario debe solicitar de nuevo el perfil.

## Rigor

- [ ] terreno no se llama edificio.
- [ ] DEM no se presenta como mapa 3D urbano.
- [ ] perfil despejado no se presenta como LOS garantizada.
- [ ] LOS/NLOS 3GPP no cambia automáticamente.
- [ ] 60% F1 se identifica como referencia de planificación.
- [ ] no se calcula todavía pérdida completa por difracción.
