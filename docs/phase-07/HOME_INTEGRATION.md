# Integración de la página principal

## Decisión

La interconexión de módulos se realiza en **Fase 7**.

No se deja para las fases finales porque ya existen dos herramientas maduras:

- `/calculadora`
- `/planner`

La portada ahora funciona como una capa de navegación y explicación del sistema.

## Responsabilidad de `/`

La página principal debe:

1. explicar qué es JIW Planner;
2. permitir elegir herramienta;
3. explicar la diferencia entre calculadora y planificador;
4. mostrar el flujo académico;
5. mostrar capacidades implementadas;
6. recordar el alcance del proyecto.

## Responsabilidad de `/calculadora`

Estudio paramétrico y matemático.

## Responsabilidad de `/planner`

Estudio espacial:

- geografía;
- propagación;
- antena;
- cobertura;
- terreno.

## Evolución posterior

En Fase 8 y Fase 9 la portada se ampliará con:

- modo IMT-2030 experimental;
- asesor técnico para Colombia.

No será necesario rediseñar nuevamente la arquitectura de navegación.
