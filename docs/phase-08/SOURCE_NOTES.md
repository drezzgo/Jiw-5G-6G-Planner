# Fuentes — Fase 8

Verificación: 2026-09-16.

## ITU-R M.2160-0

Estado:

`In force`

Ubicación de capacidades:

- §4
- páginas PDF 15–18

Ejemplos publicados:

- peak data rate: 50, 100 y 200 Gbit/s;
- user experienced data rate: 300 y 500 Mbit/s;
- mobility: 500–1.000 km/h;
- latency: 0,1–1 ms;
- positioning: 1–10 cm.

La recomendación indica que estos valores son objetivos estimados para
investigación y estudio y que no tienen que alcanzarse simultáneamente.

## ITU — marzo 2026

ITU informó que WP 5D acordó requisitos técnicos de desempeño para IMT-2030.

La publicación indicó que la aprobación formal por el grupo superior se esperaba
para diciembre de 2026.

Por tanto, a fecha de verificación:

- el proceso está avanzado;
- no debemos tratar la interfaz radio IMT-2030 como completamente finalizada.
