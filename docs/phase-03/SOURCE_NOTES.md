# Fuentes y alcance — Fase 3

Fecha de verificación: 2026-09-16.

## 3GPP / ETSI — n78

Documento usado para el perfil implementado:

**ETSI TS 138 101-1 V18.7.0 (2024-11)**  
equivalente a **3GPP TS 38.101-1 version 18.7.0 Release 18**.

El documento identifica:

- n78;
- 3300–3800 MHz;
- TDD.

Para la calculadora se fija SCS 30 kHz y las combinaciones de channel bandwidth correspondientes al perfil documentado.

URL:

https://www.etsi.org/deliver/etsi_TS/138100_138199/13810101/18.07.00_60/ts_13810101v180700p.pdf

## ITU-R M.2160-0

**Framework and overall objectives of the future development of IMT for 2030 and beyond**

Aprobada: 2023-11-13.

La recomendación presenta para `user experienced data rate` ejemplos posibles como 300 y 500 Mbit/s, pero no deben tratarse como un requisito mínimo universal o certificación final.

URL:

https://www.itu.int/rec/R-REC-M.2160-0-202311-I/en

## Estado IMT-2030

WP 5D mantiene el proceso IMT-2030.

La aplicación por tanto utiliza la etiqueta:

`IMT-2030 experimental`

y nunca:

`cumplimiento normativo 6G final`.

URL:

https://www.itu.int/en/ITU-R/study-groups/rsg5/rwp5d/imt-2030/pages/default.aspx
