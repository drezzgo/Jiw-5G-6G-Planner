# Guía de sustentación — reglas de lenguaje

## Frases correctas

- “Bajo el modelo configurado, el enlace radio resulta viable.”
- “Este criterio se evalúa contra el perfil 5G NR seleccionado.”
- “Este valor proviene de una especificación/documento concreto.”
- “Este otro valor es un parámetro experimental del proyecto.”
- “Para IMT-2030 mostramos alineación experimental, no certificación 6G.”
- “La capacidad de Shannon es un límite teórico, no throughput 5G real.”
- “Compatibilidad tecnológica y viabilidad radio son verificaciones distintas.”

## Frases a evitar

- “La aplicación certifica 5G.”
- “Cumple todo 3GPP.”
- “Esta es una red 6G real.”
- “ITU garantiza este rendimiento en despliegue real.”
- “Si el SNR es bueno el teléfono necesariamente se conecta.”
- “El mapa demuestra cobertura real.”
- “Un valor experimental es una exigencia del estándar.”

## Preguntas que la aplicación debe permitir responder

1. ¿De dónde salió este número?
2. ¿Es entrada, cálculo, estándar o criterio del proyecto?
3. ¿Cuál ecuación se usó?
4. ¿Qué variable causó que fallara?
5. ¿Qué diferencia hay entre 5G e IMT-2030 en la evaluación?
6. ¿Por qué “no evaluable” puede ser una respuesta correcta?
7. ¿Qué parte es simulada y qué parte requeriría una prueba física?
